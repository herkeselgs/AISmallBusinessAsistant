# Tomorrow's Outreach Plan (do this, in order)

Live cockpit version with copy buttons + tracker: **https://folvra.com/founder**

## Non-negotiables for the day
- **30** businesses contacted
- **20** calls
- **10** emails / contact forms
- **5** SMS / DMs
- **3** demos booked
- **1** pilot ask

## First 2 hours
- **0:00–0:15 — Build the list.** Google Maps: `kitchen remodeler {city}`, `HVAC {city}`,
  `roofer {city}`, `plumber {city}`, `landscaping {city}`, `house cleaning {city}`. Grab
  business, owner first name (from review replies / About), phone, website contact form.
  **Flag anyone "Sponsored" or on Angi/Thumbtack — they already pay for leads → call first.**
  Fill the tracker at /founder.
- **0:15–0:20 — Warm up.** Open folvra.com + folvra.com/dashboard. Run the demo out loud once.
- **0:20–1:20 — Call.** Lead-buyers first. 30-sec call script. No pickup → voicemail + immediate
  SMS. Aim 20+ dials, book 2–3 demos.
- **1:20–2:00 — Async.** Email 1 + SMS to everyone you couldn't reach. Log every touch. Update /yc.

## The loop for each prospect
1. Call → if answered, run the call script → book a 5-min demo (or do it right there).
2. No answer → voicemail + SMS with the link.
3. Log in tracker: contacted, replied, demo, pilot, notes (trade, how they handle leads, the ONE
   pain, objection, next step + date).
4. +2 days: follow-up email (Email 2), then Email 3 two days after.

## Where leads to target come from
Highest intent → businesses **already spending on leads**: Google Ads (Sponsored), Angi, Thumbtack,
Yelp Ads. They feel slow-follow-up pain the most and have budget. Next: anyone with a contact form
and 20–100 reviews (real, reachable, owner-run).

## Daily target ladder (3 weeks to YC-ready)
- Week 1: 10 pilots started, 100+ contacted, first testimonials.
- Week 2: convert 3+ pilots to paying, tighten the demo from what you hear.
- Week 3: 5+ paying, dollar-ROI quotes, a clean traction story (see `07-yc-metrics.md`).
